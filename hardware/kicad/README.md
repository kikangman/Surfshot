# Surfshot KiCad 회로도 — Rev A

ESP32 개발보드 1개, 외부 승압 모듈 2개, ULN2003A 2개로 5선 유니폴라 모터 2개를 구동하는 회로도입니다. 2026-10-28 작성.

## 열기

KiCad에서 `Surfshot.kicad_pro`를 열고 `Surfshot.kicad_sch`를 선택하세요. 회로도 파일을 직접 열어도 됩니다. KiCad 10.0.5에서 로드, PDF/SVG 출력, ERC 검사를 확인했습니다. 심벌 정의는 회로도에 내장되어 있습니다.

로컬 다운로드 ZIP에는 PDF와 PNG 미리보기도 포함됩니다. GitHub에는 편집용 프로젝트·회로도와 이 설명서를 저장합니다. KiCad의 인쇄/내보내기로 집에서도 PDF를 만들 수 있습니다.

**이 파일은 연결된 전기 회로도이며 PCB 배치·배선 파일은 아닙니다.** 실제 모듈과 커넥터 모델이 정해지지 않아 커넥터 및 커패시터 풋프린트는 미지정입니다. U1/U2에는 DIP-16, 저항에는 일반 축형 풋프린트를 임시 지정했습니다. 실물 패키지와 대조해야 합니다.

## 커넥터

| 커넥터 | 핀 | 연결 |
|---|---|---|
| J1 배터리 | 1 / 2 | 보호회로를 거친 배터리 + / GND |
| J2 ESP32 인터페이스 | 1 / 2 | +5V_M / GND |
| J2 | 3 / 4 / 5 / 6 | A_IN1 / A_IN2 / A_IN3 / A_IN4 |
| J2 | 7 / 8 / 9 / 10 | B_IN1 / B_IN2 / B_IN3 / B_IN4 |
| J3 5V 승압기 | 1 / 2 / 3 / 4 | IN+ / IN− / OUT+ (+5V_M) / OUT− |
| J4 12V 승압기 | 1 / 2 / 3 / 4 | IN+ / IN− / OUT+ (+12V_M) / OUT− |
| J5 5V 모터 | 1 | 모터 공통선 → +5V_M |
| J5 | 2 / 3 / 4 / 5 | A_COIL1 / A_COIL2 / A_COIL3 / A_COIL4 |
| J6 12V 모터 | 1 | 모터 공통선 → +12V_M |
| J6 | 2 / 3 / 4 / 5 | B_COIL1 / B_COIL2 / B_COIL3 / B_COIL4 |

J2는 연결 하네스의 논리 인터페이스입니다. **ESP32 보드에 인쇄된 실제 핀 번호가 아닙니다.** 보드 모델에 맞는 출력 가능한 GPIO 8개를 선택해 J2의 3~10번과 연결합니다. J3/J4/J5/J6 역시 실제 제품 커넥터의 핀 배열을 확인하기 전에는 그대로 꽂지 않습니다.

## 드라이버 및 전원

- U1은 5V 모터, U2는 12V 모터입니다. 기구의 팬/틸트 중 어느 축인지는 실물 확인 후 정합니다.
- ULN2003A 입력 1~4번은 J2의 해당 제어 신호, 출력 16/15/14/13번은 해당 모터 코일선입니다.
- ULN의 9번 COM과 모터 공통선은 해당 모터의 +전원에 연결합니다. 8번은 GND입니다.
- 미사용 입력 5/6/7번은 GND, 미사용 출력 10/11/12번은 명시적으로 미연결입니다.
- R1~R8은 입력을 LOW로 유지하기 위한 47kΩ 풀다운입니다. 펌웨어도 시작 시 8개 출력을 LOW로 초기화하고 통신 단절 시 정지시켜야 합니다.
- C1/C3은 100nF, C2/C4는 100µF/25V 초안값입니다. 특히 벌크 용량은 승압기의 허용 출력 커패시턴스, 기동, 안정성 조건과 실측 부하 응답을 확인해 확정합니다. 기존 모듈에 포함된 커패시터와 합산합니다.
- 모든 GND는 공통이며, 비절연 승압 모듈 기준입니다. +5V_M와 +12V_M는 연결하지 않습니다.
- ESP32는 5V 입력을 지원하는 개발보드 기준입니다. USB와 외부 5V 동시 사용은 해당 보드 회로를 먼저 확인합니다.
- 충전기와 배터리 보호회로는 외부 구성으로 가정합니다. 회로도의 PWR_FLAG는 ERC용 표시이며 실물 부품이 아닙니다.

## 검증 결과와 남은 일

- KiCad 10.0.5 ERC: **오류 0, 경고 0**, 위반 제외 없이 확인.
- 내보낸 넷리스트에서 **80개 핀–네트 연결**을 배선 계획과 대조했습니다. 미사용 출력 6개도 미연결로 확인했습니다.
- 5V·12V 전원 네트 분리와 각 드라이버 COM, 모터 공통선, GND 연결을 확인했습니다.
- PDF 미리보기의 글자와 배선 배치를 확인했습니다.

ERC 통과는 실제 전류 용량·토크·발열이나 모듈 호환성을 보장하지 않습니다. 다음 항목은 아직 미확정입니다.

1. ESP32 모델과 GPIO 번호.
2. 모터의 실제 공통선·코일 순서·커넥터 핀 배열과 코일 저항/전류.
3. 3.3V 입력에서 ULN2003A의 구동 여유와 열 조건.
4. 승압기 출력 전류와 배터리/보호회로의 허용 전류. 기존에 검토한 12V/0.3A 모듈이 충분한지는 미확인.
5. 커패시터 최종 용량과 실제 부품 풋프린트.

부품을 확인한 다음 한 축씩 저속 시험 → 두 축 동시 시험 순으로 진행합니다.

핀 기준: [Texas Instruments ULN2003A 데이터시트](https://www.ti.com/lit/gpn/ULN2003A). 별도 보드의 미확인 10핀 ULN2002 마킹 IC와 이 설계의 16핀 ULN2003A는 구분합니다.
