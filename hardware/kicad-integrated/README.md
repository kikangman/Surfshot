# Surfshot 통합 회로 Rev B0.1

직접 PCB 설계를 위한 **2장짜리 KiCad 회로 초안**입니다. PCB 배치·배선 및 제작용 Gerber는 아직 없습니다. KiCad 10.0.5에서 `Surfshot_Integrated.kicad_pro`를 열면 됩니다. 기존 모듈 연결 Rev A와 별도 프로젝트입니다.

## 구성

- 보호된 1셀 배터리(설계 입력 3.0–4.2V) → TPS61089 승압 회로 2개 → 5V/12V 모터 전원.
- 5V → TPS62162 고정 3.3V 벅 → ESP32-WROOM-32E-N4.
- ULN2003A SOIC-16 두 개로 5선 유니폴라 모터 두 개 제어.
- RESET/BOOT 버튼, 3.3V UART 다운로드 헤더, LoRa SPI 확장 헤더, 배터리 ADC.
- ESP32는 개발보드 대신 안테나·플래시가 포함된 납땜형 RF 모듈을 사용합니다. 충전/BMS와 주전원 차단 스위치는 외부에 둡니다.

## 파일

- `Surfshot_Integrated.kicad_sch`: ESP32, 3.3V, 모터 드라이버.
- `Power.kicad_sch`: IC 수준 5V/12V 승압 회로.
- `BOM.csv`: 67개 부품의 초안. DNP 표시 부품은 기본 미실장.
- `DESIGN_NOTES.md`: 계산 전제, 핀맵, 다음 검증.

## 검사 결과와 한계

KiCad 10.0.5 ERC 오류·경고 **0건**, 내보낸 XML netlist의 **238개 핀 연결**을 설계 핀맵과 대조했습니다. PDF 두 페이지를 시각 검토했습니다. ERC 통과는 실제 전류·발열·안정성 검증이 아닙니다. 시뮬레이션 및 실물 시험은 수행하지 않았습니다.

**제작 승인 전 초안입니다.** 모터 코일 저항/전류, 실제 하네스, 배터리 방전 정격, 케이스 치수가 필요합니다. 인덕터·퓨즈·커넥터의 정확한 부품/풋프린트는 미선정이며, 지정된 나머지 풋프린트도 구매할 실제 부품과 대조해야 합니다.

전원 목표는 5V 1A(모터+로직 합계), 12V 0.6A이며 검증된 연속 출력 정격이 아닙니다. 3V 입력, 효율 85% 가정 시 약 4.8A가 필요합니다. 배터리와 보호회로가 이를 지원하는지는 미확인입니다.

## B0.1 도면 정리

IC 주변 디커플링·피드백·보상 회로와 모터 풀다운을 직접 배선했습니다. 부품 번호·값과 238개 핀의 전기적 연결은 B0와 동일합니다. 네트 라벨은 블록 간 신호와 전원 연결에 사용합니다. `Surfshot.kicad_sym` 및 `sym-lib-table`은 읽기 쉽게 핀을 배치한 TPS61089 심볼 라이브러리이며 프로젝트 폴더에 함께 유지합니다. 실제 IC 핀 번호는 변경하지 않았습니다.

사용자가 지정한 기준: 18650 1개, PCB 약 80×50mm. 현재 도면의 ESP32는 WROOM 구성으로, S3 SuperMini 헤더 전환은 실제 보드 핀맵을 받은 뒤 반영합니다.
