# Rev B0 설계 노트

## 전원 계산과 부품 조건

TPS61089 PWM 기준 Vref=1.212V, 하단 FB 저항 100kΩ. 상단 312kΩ → 4.993V; 887kΩ → 11.962V. PFM 경부하 전압은 PWM 값과 달라질 수 있습니다. FB 저항 0.1%, 주파수/전류 제한 저항 1%를 가정했습니다.

| 항목 | 5V | 12V |
|---|---:|---:|
| 목표 출력 전류 | 1.0A, 로직 포함 | 0.6A |
| 인덕터 | 2.2µH, Isat ≥8A | 2.2µH, Isat ≥8A |
| FSW 저항, SW로 연결 | 316kΩ | 287kΩ |
| ILIM 저항 | 255kΩ | 169kΩ |
| 전형적 피크 제한 1030000/R | 4.04A | 6.09A |
| COMP 직렬 R/C | 8.66kΩ / 12nF | 24.9kΩ / 15nF |
| COMP 병렬 C | 22pF | 10pF, DNP |
| 출력 MLCC | 22µF/25V ×3 | 22µF/25V ×3 |

스위칭 주파수 약 500kHz는 입력 3.7V에서 계산한 시작값입니다. 전류 제한은 공차 및 온도에 따라 달라지며 최소 한계와 인덕터 리플을 함께 검증해야 합니다. 인덕터는 포화뿐 아니라 RMS 정격, DCR, 온도 상승도 확인합니다.

보상 계산은 실효 출력 용량 40µF, ESR 5mΩ, 입력 3V, 효율 85%, 전류 감지 0.08Ω, 오차 증폭기 190µS를 가정했습니다. 목표 교차 주파수는 5V에서 10kHz, 12V에서 5kHz입니다. 실제 MLCC DC 바이어스 곡선과 PCB 기생성분을 반영한 부하 과도응답/루프 검증이 필요합니다. 명목 합계 66µF만으로 실효 40µF를 보장하지 않습니다.

최대 목표 전력은 5×1+12×0.6=12.2W. 배터리 전류는 12.2/(3×0.85)=4.78A 추정입니다. F1 6.3A는 임시값이며 보호회로/배선/커넥터 및 돌입전류에 맞게 다시 선정합니다. 역극성 보호는 포함하지 않았습니다.

TPS62162는 5V에서 3.3V를 생성하며 2.2µH/22µF 출력 필터를 사용합니다. PG 오픈드레인은 ESP_EN에 연결하고 10kΩ/1µF 리셋 RC를 사용합니다. 5V 1A 예산에는 이 전원의 입력 전류가 포함됩니다. 예를 들어 3.3V 0.5A, 벅 효율 90% 가정이면 5V 측 약 0.37A를 소비하므로 모터에는 약 0.63A만 남습니다.

## 핀맵

| 기능 | ESP32 GPIO |
|---|---|
| 모터 A IN1–4 | 13, 14, 16, 17 |
| 모터 B IN1–4 | 25, 26, 27, 32 |
| UART TX / RX | 1 / 3 |
| LoRa SCK / MISO / MOSI | 18 / 19 / 23 |
| LoRa CS / RESET / DIO | 21 / 22 / 33 |
| 배터리 ADC | 34, 100kΩ/100kΩ 분압+100nF |

J4는 5V 모터, J5는 12V 모터입니다. 두 커넥터 모두 1=공통 전원, 2–5=코일 1–4. 실제 선 색상과 순서는 아직 확인하지 않았습니다. ULN2003A COM(9)은 해당 모터 전원, E(8)는 GND. 사용하지 않는 입력은 GND, 출력은 NC입니다.

J2: 1=GND, 2=ESP TX, 3=ESP RX, 4=ESP_EN. 외부 USB-UART는 3.3V 신호 수준만 사용하고 TX/RX를 교차 연결합니다. 전원은 배터리에서 공급합니다. BOOT를 누른 채 RESET을 눌렀다 놓아 다운로드합니다. USB 회로와 자동 다운로드 회로는 없습니다.

J3: 1=3.3V, 2=GND, 3=SCK, 4=MISO, 5=MOSI, 6=CS, 7=RESET, 8=DIO. LoRa 모듈 종류에 따라 BUSY/추가 IRQ 또는 전원 예산 변경이 필요할 수 있습니다. RF 모듈/안테나는 아직 포함하지 않았습니다.

## 다음 검증 및 PCB 조건

1. 두 모터의 공통선–각 코일 저항, 정격/실측 전류, 하네스 순서를 확인합니다. ULN2003A의 3.3V 입력 구동 능력과 VCE(sat), 동시 2상 발열을 확인하고 필요하면 드라이버를 변경합니다. 500mA 단일 채널 최대값을 다채널 연속 정격으로 사용하지 않습니다.
2. 배터리 용량/방전 전류/BMS 차단값 및 케이스 보드 공간을 확정합니다. 부품 구매번호와 모든 풋프린트를 확정한 뒤 PCB 배치·배선을 시작합니다.
3. 4층 PCB와 연속 GND면을 기준으로 검토합니다. IC별 입력 바이패스, BOOT/VCC, 출력 커패시터를 가까이 배치하고 SW 고전류 루프를 짧게 유지합니다. FB/COMP와 ADC는 SW에서 떨어뜨리고 ESP32 안테나 keepout을 지킵니다.
4. 전류 제한 전원으로 무부하 전압부터 확인하고 한 축씩 구동한 뒤 동시 구동, 무선 송신, 부하 과도응답, 온도 및 저전압 동작을 측정합니다.
5. 펌웨어 초기화 시 모든 모터 핀 LOW. 통신 단절 시 정지, 정지 후 코일 해제, 3.2V 이하 모터 비활성화를 구현합니다. BMS가 하드웨어 과방전 보호를 담당합니다. 승압 EN을 끄는 것만으로 출력이 절연되지는 않습니다.
